AI Voice Agents Challenge – Day 1 Project

Built with Murf Falcon TTS + LiveKit Agents + React Frontend



This project is part of the AI Voice Agents Challenge by Murf.ai

&nbsp;where participants build 10 AI Voice Agents in 10 days using Murf Falcon (fastest TTS) and LiveKit voice AI infrastructure.



Backend	:

Python, LiveKit Agents, Murf Falcon TTS, Deepgram STT, Gemini LLM

Frontend :

React / Next.js, LiveKit Client

Realtime Communication :

WebRTC via LiveKit

Package Managers :

uv (Python), pnpm (Node.js)





##### **Setup Instructions:** 

Prerequisites



Python 3.9+



uv package manager



Node.js 18+ and pnpm



LiveKit Server (self-hosted) or LiveKit Cloud



API Keys:



LIVEKIT\_API\_KEY / LIVEKIT\_API\_SECRET



MURF\_API\_KEY



DEEPGRAM\_API\_KEY



GOOGLE\_API\_KEY



##### **Features Implemented (Day 1):**



Realtime conversational voice agent



Murf Falcon TTS integration



Deepgram speech recognition



Gemini-powered responses



Audio level visualization UI
